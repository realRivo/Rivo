# CityBeyond

CityBeyond is a mobile-first 3D city-building simulator made with Godot 4.

## Current foundation
- Godot 4 project
- OpenGL Compatibility renderer for Android-friendly startup
- Procedural 3D city grid
- Isometric-style camera
- Road and zoning simulation foundation
- Automatic building growth foundation

## Target
A deep city simulator with roads, utilities, RCI demand, population, jobs, traffic, services, public transport, economy, disasters, save/load, and scalable 3D assets.
